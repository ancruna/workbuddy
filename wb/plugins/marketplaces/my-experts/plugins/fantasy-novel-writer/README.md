# 墨玄 - 网文小说写作专家

专注东方玄幻与仙侠网文的协作式写作专家，擅长世界观架构、修炼体系设计、爽点节奏把控与快节奏连载创作，适配番茄/七猫等平台调性。

## 类型

Agent 型（单个 AI 专家）

## 功能

- **世界观架构**：搭建自洽的天地格局、势力版图与力量规则
- **修炼体系设计**：境界阶梯、功法丹药、突破爽点一站式设计
- **爽点与节奏把控**：黄金三章、千字一钩、章末断章的番茄节奏模型
- **人物塑造**：主角弧光、金手指、反派动机链
- **大纲规划**：从一句话创意到全书卷纲、章纲、细纲的完整拆解
- **正文创作**：按网文语感直接产出高质量章节并持续优化

## 使用示例

- 帮我构思一部东方玄幻小说的世界观与修炼体系
- 根据大纲写第一章正文，要突出爽点和开篇钩子
- 帮我把这段情节改得更符合番茄节奏，增强冲突与期待感

## 安装

将专家包目录放到专家目录下：

```
/Users/didi/.workbuddy/plugins/marketplaces/my-experts/plugins/fantasy-novel-writer/
```

然后运行注册命令使其可见：

```bash
python3 scripts/register_expert.py <expert-dir>
```

## 打包分享

```bash
zip -r fantasy-novel-writer.zip fantasy-novel-writer/
```
