# 炼器等级设定

> 炼器师是修仙界最尊贵的职业之一，与炼丹师、阵法师并称三艺。本设定与《修仙界等级设定.md》配套使用。

---

## 一、炼器师等级（自下而上）

### 1. 炼器学徒
- **对应修为**：炼气期。
- **能力**：只能淬炼材料、打磨法器毛坯，为师父打下手。
- **标识**：无铭牌。

### 2. 一品炼器师 → 三品炼器师
- **对应修为**：筑基期。
- **能力**：可独立炼制**法器**（下品至极品）。
- **考核**：由炼器公会现场炼制三件指定法器，成二留一。
- **地位**：小宗门争抢的客卿，凡俗王朝供奉的"神匠"。

### 3. 四品炼器师 → 六品炼器师
- **对应修为**：金丹期。
- **能力**：可炼制**灵器**，初步掌握"器纹烙刻"——在器物内部铭刻灵纹，令法宝威力倍增。
- **关键分野**：五品是分水岭，能否烙刻器纹决定上限。
- **地位**：大宗门长老级待遇，一域名家。

### 4. 七品炼器师 → 九品炼器师
- **对应修为**：元婴期以上。
- **能力**：可炼制**宝器**，掌握"器灵初蕴"——以自身精血温养器胚，孕育器灵雏形。
- **地位**：炼器公会供奉，化神老怪也要客客气气求购。

### 5. 器宗（器道大师）
- **对应修为**：化神期以上。
- **能力**：可炼制**后天灵宝**。一器成，天地鸣，方圆百里异象丛生。
- **特征**：开创独门器道（如"焚天器道""寒渊器道"），器出有名，仿者必遭器灵反噬。

### 6. 器圣
- **对应修为**：合体期以上。
- **能力**：可修补**先天灵宝**，窥探"以天地为炉"之境。传说可为渡劫期强者炼制渡劫至宝。

### 7. 器祖 / 器道通神
- **对应修为**：大乘期，一界不出一人。
- **能力**：传说中"炼器即炼世界"——将一缕世界本源封入器中，可炼**仙器雏形**。
- **禁忌**：器祖炼器必引天劫，故一生只出三器，三器出而人陨。

## 二、炼器师等级速查表

| 品阶 | 对应修为 | 可炼之物 | 江湖地位 |
|---|---|---|---|
| 学徒 | 炼气 | 打下手 | 无 |
| 一~三品 | 筑基 | 法器 | 小宗客卿 |
| 四~六品 | 金丹 | 灵器（含器纹） | 一域名家 |
| 七~九品 | 元婴+ | 宝器（含器灵雏形） | 公会供奉 |
| 器宗 | 化神+ | 后天灵宝 | 开宗立派 |
| 器圣 | 合体+ | 补先天灵宝 | 一界名宿 |
| 器祖 | 大乘 | 仙器雏形 | 传说 |

> **核心规则**：炼器品阶受修为**硬性压制**——修为不够，神识与灵力无法驾驭地火、无法烙刻高阶器纹，强行越阶炼器轻则吐血、重则炉毁人亡。

## 三、炼器工艺（名词表）

### 1. 材料
- **凡材**：玄铁、精金——凡俗兵器用。
- **灵材**：炼器主流，分下品/中品/上品/极品（如星辰砂、地心炎髓、万年寒铁）。
- **神材**：蕴含法则之力（如真龙骨、凤凰翎、虚空石），炼灵宝以上必备。
- **仙材**：仙界之物，下界只在传说中出现。

### 2. 火焰（炼器师的核心竞争力）
| 火焰 | 品级 | 特点 |
|---|---|---|
| 地火 | 凡火 | 借地脉之火，稳定但弱 |
| 真火 | 灵火 | 修士自身真火，随修为增长 |
| 异火/天火 | 神火 | 天地孕育（如九幽冥火、青莲地心火），可夺 |
| 心火 | 道火 | 器道大成自生之火，"以心炼器" |

### 3. 工序（九步古法）
备材 → 熔炼 → 去杂 → 凝胚 → **烙纹** → **蕴灵** → 淬火 → 开锋 → 认主

> 烙纹与蕴灵是宝器以上成败关键，也是炼器师品阶的分水岭。

### 4. 炼器三大流派
- **豪放派**：以力破巧，一锤定音，器物大气厚重。成器快，废品率高。
- **精工派**：纹路繁复，层层铭刻，器物精妙多变。废品率低，耗时极长。
- **天工派**：师法自然，借天地之力炼器，追求"无人工痕迹"。传承稀少，非大机缘不可得。

## 四、失败与代价（写作冲突点）

1. **炉毁**：材料尽毁，血本无归——炼器师破产常态。
2. **反噬**：烙纹失败遭灵纹反噬，轻伤神识，重则痴呆。
3. **器劫**：炼制灵宝以上引动天劫，劫毁器碎人重伤。
4. **器灵叛主**：蕴灵时心术不正，器灵觉醒后第一件事就是弑主。
5. **夺火之危**：异火有灵，强行收取者被焚为灰烬者十有八九。

## 五、与法宝品阶的对应关系

法器 → 灵器 → 宝器 → 灵宝 → 仙器（详见《修仙界等级设定.md》配套体系）

> 一件极本品阶法宝 = 同品阶炼器师 + 顶级材料 + 高阶火焰 + 三分运气，缺一不可。
> 主角若走炼器路线，建议从"废材学徒 + 意外获得天工传承/异火"起手。
